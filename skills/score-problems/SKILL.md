description: Groups the checked pains in research/ into problems and scores them. Use when I ask to score, rank or compare problems.

Read every file in research/ except scores.md.

1. Use only rows stamped FOUND or CLOSE, and rows I checked by hand. Ignore NOT FOUND, COULD NOT OPEN and everything under "My guesses".
2. Group pains that come from the same need into one problem. Write each problem as: "<who> struggle to <what> because <why>". Name the pain, never a solution.
3. Score each problem from 1 to 5:
   - Pain: how much it costs them (money, hours, stress)
   - Frequency: how often it happens
   - Paying today: are they already spending money or time on a workaround
   - Buildable: could a beginner build a first web version in 3 sessions with Claude Code (no hardware, no licence, no marketplace that needs two sides on day one)
   - AI edge: would AI make the fix clearly better, not just add a chatbot
   Write "?" for Reachable and I care. Only I can score those.
4. Every score needs a short reason that points to row numbers, like (tuition #3, #7).
5. Flag kill signals: needs hardware; needs a licence or medical or money records; needs both sides of a marketplace on day one; fewer than 3 receipts.
6. Save research/scores.md: a ranked table (problem, receipts, the 5 scores, flags), then the top 3 with their 2 best quotes and links.

Reply with the top 3, one line each.
